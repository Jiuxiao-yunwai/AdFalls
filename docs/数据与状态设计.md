# 数据与状态设计

## Room 需要保存

- 广告标题、描述、频道、类型
- 图片地址、视频地址
- AI 摘要、AI 标签
- 点赞、收藏
- 点赞数、收藏数、分享数
- 点击数、曝光数

## AdEntity 草案

```kotlin
@Entity(tableName = "ads")
data class AdEntity(
    @PrimaryKey val id: String,
    val title: String,
    val description: String,
    val imageUrl: String?,
    val videoUrl: String?,
    val type: String,
    val channel: String,
    val tags: String,
    val aiSummary: String,
    val liked: Boolean,
    val collected: Boolean,
    val likeCount: Int,
    val collectCount: Int,
    val shareCount: Int,
    val clickCount: Int,
    val exposureCount: Int
)
```

`tags` 先用逗号分隔字符串保存，例如：

```text
运动,学生党,性价比
```

## AdDao 草案

```kotlin
@Dao
interface AdDao {
    @Query("SELECT * FROM ads WHERE channel = :channel")
    fun observeAdsByChannel(channel: String): LiveData<List<AdEntity>>

    @Query("SELECT * FROM ads WHERE id = :id LIMIT 1")
    fun observeAdById(id: String): LiveData<AdEntity?>

    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun insertAds(ads: List<AdEntity>)

    @Query("UPDATE ads SET liked = :liked, likeCount = :count WHERE id = :id")
    suspend fun updateLike(id: String, liked: Boolean, count: Int)

    @Query("UPDATE ads SET collected = :collected, collectCount = :count WHERE id = :id")
    suspend fun updateCollect(id: String, collected: Boolean, count: Int)

    @Query("UPDATE ads SET clickCount = clickCount + 1 WHERE id = :id")
    suspend fun addClick(id: String)

    @Query("UPDATE ads SET exposureCount = exposureCount + 1 WHERE id = :id")
    suspend fun addExposure(id: String)
}
```

## 状态同步约定

- 点赞、收藏、点击、曝光、分享都写 Room。
- 列表页和详情页观察同一条广告数据。
- Repository 不长期保存业务状态。
- 当前 Tab、搜索词、加载中状态放 ViewModel。
- 视频播放器实例可以缓存，但播放状态要能同步到页面。
