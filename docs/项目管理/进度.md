### 阶段 2：Room 数据层

状态：已完成。

目标：

- 新增 `AppDatabase`。
- 新增 `AdEntity`。
- 新增 `AdDao`。
- 将现有 mock 数据写入 Room。

完成后总结：

- 新增 Room 依赖：`room-runtime`、`room-ktx`、`room-compiler`，使用 KSP 生成代码。
- 新增 `data/local` 包，包含 `AppDatabase`、`AdEntity`、`AdDao`。
- `AdEntity` 覆盖广告基础信息、互动状态、统计字段和视频模拟状态，`tags` 暂用逗号分隔字符串保存。
- `AdRepository` 保留 mock 数据生成逻辑，首次启动将 50 条固定 mock 广告写入 Room。
- 列表、详情、搜索、刷新、加载更多、点赞、收藏、分享、点击、曝光和视频状态都通过 Repository 读写 Room。
- 信息流加载从未请求过的数据中选取，当前频道无剩余数据时显示“到底了”。
- `FeedViewModel`、`DetailViewModel` 和 Activity 仍不直接访问 DAO、Entity 或 Room。
