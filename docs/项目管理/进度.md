## 阶段记录

### 阶段 0：基础 Demo

状态：已完成。

完成内容：

- 使用 Kotlin + XML 搭建 Android 项目。
- 使用 RecyclerView 实现广告信息流。
- 支持精选、电商、本地三个频道。
- 支持搜索、下拉刷新、上滑加载。
- 实现大图、小图、视频三种广告卡片。
- 实现详情页跳转。

遗留问题：

- 数据和状态仍保存在内存 Repository 中。
- Activity 内承担了较多状态管理和业务调用。

### 阶段 2：Room 数据层

状态：已完成。

目标：

- 新增 `AppDatabase`。
- 新增 `AdEntity`。
- 新增 `AdDao`。
- 将现有 mock 数据写入 Room。

完成后总结：

- 新增 Room 依赖：`room-runtime`、`room-ktx`、`room-compiler`，使用 KSP 生成代码。
- 新增 `data/local` 包，包含 `AppDatabase`、`AdEntity`、`AdDao`。
- `AdEntity` 覆盖广告基础信息、互动状态、统计字段和视频模拟状态，`tags` 暂用逗号分隔字符串保存。
- `AdRepository` 保留 mock 数据生成逻辑，首次启动将 50 条固定 mock 广告写入 Room。
- 列表、详情、搜索、刷新、加载更多、点赞、收藏、分享、点击、曝光和视频状态都通过 Repository 读写 Room。
- 信息流加载从未请求过的数据中选取，当前频道无剩余数据时显示“到底了”。
- `FeedViewModel`、`DetailViewModel` 和 Activity 仍不直接访问 DAO、Entity 或 Room。

### 阶段 3：状态同步

状态：已完成。

目标：

- 列表页和详情页观察同一份 Room 数据。
- 点赞、收藏、分享、点击、曝光全部落库。
- 去掉内存 Repository 中的长期业务状态。

完成后总结：

- `AdRepository` 暴露 `observeAdsByChannel(channel)` 和 `observeAdById(id)`，列表页和详情页观察同一份 Room 数据。
- `FeedViewModel` 新增 `FeedUiState`，使用 `StateFlow` 保存当前频道、搜索词、广告列表、加载更多和到底状态。
- `DetailViewModel` 新增 `DetailUiState`，使用 `StateFlow` 保存详情广告、加载和空状态。
- `MainActivity` 改为收集首页 `StateFlow` 后自动 `submitAds()`，点击、点赞、收藏、分享、曝光、加载更多等操作不再手动 `renderList()`。
- `DetailActivity` 改为收集详情 `StateFlow` 后自动刷新 UI，点赞、收藏、分享和视频模拟状态变化不再手动 `bind()`。
- DAO 写入方法已改为 `suspend`，数据库移除 `allowMainThreadQueries()`，Repository 写入 Room 后依靠 Flow 自动推送新状态。

### 阶段 5：视频能力

状态：视频能力收尾验证中。

已完成内容：

- 接入 AndroidX Media3：`media3-exoplayer` 和 `media3-ui`。
- 广告数据模型新增 `videoUrl`，视频广告使用本地生成的 15 秒 mock 视频资源。
- Room schema 升级到版本 3，并启用开发期破坏式迁移以刷新旧数据。
- 视频卡片和详情页使用 `PlayerView` 承载真实播放器画面。
- `VideoPlaybackPool` 升级为共享 ExoPlayer 资源池，同一时间复用一个播放器实例。
- 播放新视频时会暂停旧视频，并把播放、暂停、静音状态写回 Room。
- 列表视频滑出可视区域后自动暂停。
- 本轮收尾整理视频播放、暂停、静音逻辑。
- 本轮收尾补充频道切换时暂停旧频道视频的保护。
- 本轮收尾补充播放器最终释放入口。
- 本轮新增信息流视频自动播放调度：完全进入 RecyclerView 可视区域后自动播放，完全离屏后自动暂停。
- 本轮新增按广告 id 保存播放进度，滑回同一视频时尽量从上次进度继续播放。
- 本轮整理视频控件：自动播放时隐藏播放和进度控件，点击后显示中央播放/暂停和底部进度，1 秒无操作后淡出。
- 本轮整理静音控件：右上角静音按钮常驻，静音状态在后续播放视频间共享。
- 本轮减少播放/暂停点击闪屏：播放和静音状态使用局部刷新，避免整卡重绑播放器。
- `AdAdapter` 只暴露当前绑定广告和 PlayerView，自动播放决策仍由 MainActivity / FeedViewModel / VideoPlaybackPool 协作完成。

待继续：

- 继续验证列表完全入屏自动播放、完全离屏自动暂停和多视频切换行为。
- 继续验证点击视频暂停/恢复、1 秒控件淡出和静音状态跨视频同步行为。
- 验证详情页进入、返回列表后的播放状态同步。
- 继续观察播放器释放时机，避免列表进入详情页时误释放共享播放器。
- 视频加载状态、错误状态和本地兜底资源作为下一步可选项。

### 阶段 6：网络和 AI 服务

状态：进行中。

已完成内容：

- 新增 `data/remote/FakeAdRemoteDataSource`，作为无服务器情况下的本地模拟远程服务。
- `AdRepository` 的刷新和加载更多流程已改为通过 `FakeAdRemoteDataSource.fetchAdPage()` 获取分页广告。
- `FakeAdRemoteDataSource` 内部从 Room 广告池读取数据，并用 `delay()` 模拟网络请求耗时。
- 保持页面、ViewModel 和 Room Flow 同步方式不变，后续可将 FakeRemote 替换为 OkHttp 实现。

- 将本地摘要替换为真实 AI 摘要。
- 将本地标签替换为真实智能标签。
- 将本地搜索扩展为对话式搜索。
- 将曝光、点击等统计上报到服务端。
