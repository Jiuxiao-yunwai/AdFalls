# 开发路线

## 近期任务

1. 整理包结构：`ui / viewmodel / data`。
2. 新增 `FeedViewModel`，把首页状态从 `MainActivity` 挪出去。
3. 新增 `DetailViewModel`，把详情页互动逻辑挪出去。
4. 接入 Room：`AppDatabase / AdEntity / AdDao`。
5. 把当前 mock 广告写入 Room。
6. 列表和详情改成观察 Room。
7. 点赞、收藏、分享、点击、曝光全部落库。
8. 再接 OkHttp 和 AI 服务。
9. 无服务器阶段先使用 `FakeAdRemoteDataSource` 模拟广告接口。
10. AI 对话式搜索先使用 `AiChatRemoteDataSource` 模拟服务端 DTO，后续再替换为真实 C/S 接口。

## 阶段拆分

| 阶段 | 内容 | 产出 |
| --- | --- | --- |
| 1 | MVVM 基础结构 | ViewModel + Repository 调整 |
| 2 | Room 数据层 | Entity、Dao、Database |
| 3 | 状态同步 | 列表和详情观察同一份数据 |
| 4 | 信息流完善 | 刷新、加载、搜索、标签过滤 |
| 5 | 视频能力 | 播放、暂停、静音、资源复用 |
| 6 | 网络和 AI | OkHttp、摘要、标签、对话搜索 |
| 7 | 收尾 | 测试、README、演示材料 |

## 注意

- 每个阶段都保持项目可运行。
- Room 接入前不要大规模改 UI。
- 网络和 AI 放后面，先保证本地数据流稳定。
- Mock 数据保留，作为离线演示和失败降级。
- 没有服务器时，先用本地 FakeRemote 模拟接口，保持 Repository 调用形态接近真实网络请求。
- AI Chat 的 Activity 和 ViewModel 只处理 `AiChatMessage`，服务端 DTO 构造和解析集中放在 Repository / Remote 层。
