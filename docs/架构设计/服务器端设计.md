# 广告信息流 App 服务器接口设计文档

## 1. 设计说明

本项目是单列滑动广告信息流 App，服务器主要负责提供广告列表、广告详情、搜索、对话式搜索、用户行为记录和收藏相关接口。

------

## 2. 接口设计

## 2.1 获取广告信息流

```text
GET /api/ads/feed
```

获取指定频道下的广告信息流，用于首页单列滑动列表。

| 参数    | 类型   | 是否必填 | 说明                                |
| ------- | ------ | -------- | ----------------------------------- |
| channel | String | 是       | 频道，如 featured、ecommerce、local |
| cursor  | String | 否       | 游标，第一次请求为空                |
| size    | Int    | 是       | 每次加载数量                        |
| userId  | Long   | 否       | 用户 ID                             |

```text
/api/ads/feed?channel=featured&cursor=&size=10&userId=10001
```

------

## 2.2 获取广告详情

```text
GET /api/ads/{id}
```

根据广告 ID 获取广告详情页数据。

| 参数   | 类型 | 是否必填 | 说明                      |
| ------ | ---- | -------- | ------------------------- |
| id     | Long | 是       | 广告 ID                   |
| userId | Long | 否       | 用户 ID，用于判断是否收藏 |

```text
/api/ads/1001?userId=10001
```

------

## 2.3 搜索广告

```text
GET /api/ads/search
```

根据关键词搜索广告。

| 参数    | 类型   | 是否必填 | 说明                 |
| ------- | ------ | -------- | -------------------- |
| keyword | String | 是       | 搜索关键词           |
| cursor  | String | 否       | 游标，第一次请求为空 |
| size    | Int    | 是       | 每次加载数量         |
| userId  | Long   | 否       | 用户 ID              |

```text
/api/ads/search?keyword=耳机&cursor=&size=10&userId=10001
```

------

## 2.4 对话式搜索

```text
POST /api/ai/chat-search
```

用户输入自然语言，服务器调用ai，理解搜索意图，并返回相关广告。

| 参数    | 类型   | 是否必填 | 说明                 |
| ------- | ------ | -------- | -------------------- |
| userId  | Long   | 否       | 用户 ID              |
| message | String | 是       | 用户输入内容         |
| cursor  | String | 否       | 游标，第一次请求为空 |
| size    | Int    | 是       | 每次加载数量         |

------

## 2.5 记录用户行为

```text
POST /api/behavior
```

记录用户对广告的操作行为，例如曝光、点击、进入详情页、播放视频、搜索等。

| 参数         | 类型   | 是否必填 | 说明     |
| ------------ | ------ | -------- | -------- |
| userId       | Long   | 是       | 用户 ID  |
| adId         | Long   | 否       | 广告 ID  |
| channel      | String | 否       | 当前频道 |
| behaviorType | String | 是       | 行为类型 |

### 行为类型

```text
EXPOSURE：曝光
CLICK：点击
DETAIL_VIEW：进入详情页
FAVORITE：收藏
UNFAVORITE：取消收藏
VIDEO_PLAY：视频播放
SEARCH：搜索
```

------

## 2.6 用户登录

```text
POST /api/user/login
```

用户登录，返回用户信息和 token。

| 参数     | 类型   | 是否必填 | 说明   |
| -------- | ------ | -------- | ------ |
| username | String | 是       | 用户名 |
| password | String | 是       | 密码   |

------

## 2.7 获取用户收藏列表

```text
GET /api/user/{id}/favorites
```

获取用户收藏的广告列表。

| 参数   | 类型   | 是否必填 | 说明                 |
| ------ | ------ | -------- | -------------------- |
| id     | Long   | 是       | 用户 ID              |
| cursor | String | 否       | 游标，第一次请求为空 |
| size   | Int    | 是       | 每次加载数量         |

```text
/api/user/10001/favorites?cursor=&size=10
```

------

## 2.8 收藏广告

```text
POST /api/user/{userId}/favorites/{adId}
```

## 2.9 取消收藏广告

```text
DELETE /api/user/{userId}/favorites/{adId}
```

| 参数 | 类型 | 是否必填 | 说明    |
| ---- | ---- | -------- | ------- |
| id   | Long | 是       | 用户 ID |
| adId | Long | 是       | 广告 ID |

------

## 3. 接口汇总

| 模块           | 接口                                  | 方法   | 作用             |
| -------------- | ------------------------------------- | ------ | ---------------- |
| 信息流模块     | `/api/ads/feed`                       | GET    | 获取广告信息流   |
| 广告详情模块   | `/api/ads/{id}`                       | GET    | 获取广告详情     |
| 搜索模块       | `/api/ads/search`                     | GET    | 关键词搜索广告   |
| 对话式搜索模块 | `/api/ai/chat-search`                 | POST   | 自然语言搜索广告 |
| 用户行为模块   | `/api/behavior`                       | POST   | 记录用户行为     |
| 用户模块       | `/api/user/login`                     | POST   | 用户登录         |
| 收藏模块       | `/api/user/{id}/favorites`            | GET    | 获取收藏列表     |
| 收藏模块       | `/api/user/{userId}/favorites/{adId}` | POST   | 收藏广告         |
| 收藏模块       | `/api/user/{id}/favorites/{adId}`     | DELETE | 取消收藏         |

------

## 4. App 调用行为流程

## 4.1 打开 App

客户端先检查本地是否存在：

```text
userId
token
```

如果已经登录，直接进入首页。

如果没有登录，可以进入游客模式，或者跳转登录页。

登录时调用：

```text
POST /api/user/login
```

------

## 4.2 进入首页

调用广告信息流接口：

```text
GET /api/ads/feed
```

请求示例：

```text
/api/ads/feed?channel=featured&cursor=&size=10&userId=10001
```

客户端拿到广告列表后，渲染单列信息流，并保存服务器返回的：

```text
nextCursor
hasMore
```

------

## 4.3 广告曝光

当广告卡片进入屏幕可见区域时，可以调用：

```text
POST /api/behavior
```

行为类型为：

```text
EXPOSURE
```

------

## 4.4 上拉加载更多

当用户滑到底部时，继续调用：

```text
GET /api/ads/feed
```

这次携带上一次返回的 `nextCursor`：

```text
/api/ads/feed?channel=featured&cursor=1001&size=10&userId=10001
```

------

## 4.5 下拉刷新

下拉刷新时重新请求信息流接口，并将 `cursor` 置空：

```text
/api/ads/feed?channel=featured&cursor=&size=10&userId=10001
```

客户端清空旧列表，用新数据替换当前列表。

------

## 4.6 切换频道

例如从精选切换到电商频道。

客户端将频道改为：

```text
ecommerce
```

然后重新请求：

```text
/api/ads/feed?channel=ecommerce&cursor=&size=10&userId=10001
```

切换频道时需要：

```text
cursor 置空
清空当前列表
加载新频道广告
```

------

## 4.7 点击广告卡片

用户点击广告卡片时，先记录点击行为：

```text
POST /api/behavior
```

行为类型为：

```text
CLICK
```

然后请求广告详情：

```text
GET /api/ads/{id}
```

请求示例：

```text
/api/ads/1001?userId=10001
```

进入详情页后，也可以记录详情页访问行为：

```text
DETAIL_VIEW
```

------

## 4.8 收藏广告

用户在广告卡片或详情页点击收藏时，调用：

```text
POST /api/user/{id}/favorites
```

收藏成功后，客户端将当前广告的：

```text
isFavorite = true
```

同时调用行为记录接口，记录：

```text
FAVORITE
```

------

## 4.10 搜索广告

用户输入关键词搜索时，调用：

```text
GET /api/ads/search
```

请求示例：

```text
/api/ads/search?keyword=耳机&cursor=&size=10&userId=10001
```

搜索结果继续向下滑动时，继续使用服务器返回的 `nextCursor` 加载更多。

------

## 4.11 对话式搜索

用户输入自然语言时，调用：

```text
POST /api/ai/chat-search
```

服务器返回回复文本和广告列表。
