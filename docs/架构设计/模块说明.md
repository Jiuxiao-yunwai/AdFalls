# 模块说明

## `ui/feed`

首页信息流模块。

- `MainActivity.kt`：首页 View 层，负责 UI 初始化、事件监听和列表渲染。
- `AdAdapter.kt`：RecyclerView 适配器，负责大图、小图、视频广告卡片绑定。

## `ui/detail`

广告详情模块。

- `DetailActivity.kt`：详情页 View 层，负责 UI 初始化、按钮监听和详情渲染。

## `ui/aichat`

AI 对话式搜索模块。

- `AiChatActivity.kt`：AI 聊天搜索 View 层，负责聊天页 UI 初始化、输入、发送、返回和消息列表渲染。
- `AiChatAdapter.kt`：RecyclerView 多类型适配器，负责用户消息、AI 消息、加载消息和错误消息气泡展示。

## `viewmodel`

页面状态和交互逻辑模块。

- `FeedViewModel.kt`：保存首页频道、搜索、加载和列表数据，封装首页全部广告交互。
- `DetailViewModel.kt`：保存当前详情广告，封装详情页点赞、收藏、分享和视频交互。
- `AiChatViewModel.kt`：保存 AI 聊天页频道、输入框、发送状态和消息列表，封装发送消息流程。

## `data/model`

数据模型模块。

- `AdModels.kt`：定义 `AdChannel`、`AdCardType`、`AdItem`。
- `AiChatMessage.kt`：定义聊天消息模型 `AiChatMessage` 和消息角色 `ChatRole`。

## `data/repository`

数据仓库模块。

- `AdRepository.kt`：统一封装固定 mock 数据池、Room 初始化、查询、搜索、刷新、加载更多、互动统计和状态更新。
- `AiChatRepository.kt`：构造 AI Chat 请求 DTO，调用远程数据源，并把响应 DTO 转换为 UI 可用的 `AiChatMessage`。

## `data/remote`

模拟远程服务和后续网络替换层。

- `FakeAdRemoteDataSource.kt`：模拟广告分页和搜索接口。
- `AiChatRemoteDataSource.kt`：模拟 AI Chat C/S 服务端响应，后续替换为 OkHttp 请求。
- `AiChatDto.kt`：定义 AI Chat 请求、历史、响应和消息 DTO，以及 DTO 到 `AiChatMessage` 的转换函数。

## `data/local`

本地 Room 数据层。

- `AppDatabase.kt`：Room 数据库入口，提供 `AdDao`。
- `AdEntity.kt`：Room 表实体，并提供 `AdItem` 和 `AdEntity` 的双向转换。
- `AdDao.kt`：广告查询、插入、互动状态和统计字段更新接口。

## `cache`

临时缓存和复用模块。

- `VideoPlaybackPool.kt`：Media3 共享播放器池，复用单个 ExoPlayer，维护当前播放广告、播放进度和共享静音状态，并把播放、暂停、静音状态写回 Repository。

## 当前阶段边界

- 不接真实 OkHttp 请求。
- 不接真实 AI 服务或大模型。
- 不引入 Compose。
- 保持现有页面和交互行为不变。
