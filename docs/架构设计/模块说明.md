# 模块说明

## `ui/feed`

首页信息流模块。

- `MainActivity.kt`：首页 View 层，负责 UI 初始化、事件监听和列表渲染。
- `AdAdapter.kt`：RecyclerView 适配器，负责大图、小图、视频广告卡片绑定。

## `ui/detail`

广告详情模块。

- `DetailActivity.kt`：详情页 View 层，负责 UI 初始化、按钮监听和详情渲染。

## `viewmodel`

页面状态和交互逻辑模块。

- `FeedViewModel.kt`：保存首页频道、搜索、加载和列表数据，封装首页全部广告交互。
- `DetailViewModel.kt`：保存当前详情广告，封装详情页点赞、收藏、分享和视频交互。

## `data/model`

数据模型模块。

- `AdModels.kt`：定义 `AdChannel`、`AdCardType`、`AdItem`。

## `data/repository`

数据仓库模块。

- `AdRepository.kt`：统一封装固定 mock 数据池、Room 初始化、查询、搜索、刷新、加载更多、互动统计和状态更新。

## `data/local`

本地 Room 数据层。

- `AppDatabase.kt`：Room 数据库入口，提供 `AdDao`。
- `AdEntity.kt`：Room 表实体，并提供 `AdItem` 和 `AdEntity` 的双向转换。
- `AdDao.kt`：广告查询、插入、互动状态和统计字段更新接口。

## `cache`

临时缓存和复用模块。

- `VideoPlaybackPool.kt`：Media3 共享播放器池，复用单个 ExoPlayer，维护当前播放广告、播放进度和共享静音状态，并把播放、暂停、静音状态写回 Repository。

## 当前阶段边界

- 不接 OkHttp。
- 不接真实 AI 服务。
- 不引入 Compose。
- 保持现有页面和交互行为不变。
