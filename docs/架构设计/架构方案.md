# 架构方案

## 目标结构

```text
ui              页面、XML、Adapter
viewmodel       页面状态和交互逻辑
data/model      数据模型
data/local      Room、Dao、Entity
data/remote     OkHttp 数据源
data/repository Repository
data/ai         AI 摘要、标签、搜索
analytics       曝光统计
cache           视频播放器复用
```

## 分层职责

| 层 | 做什么 |
| --- | --- |
| View | 展示 UI，监听点击、刷新、滚动 |
| ViewModel | 保存页面状态，调用 Repository |
| Repository | 统一拿数据、写缓存、处理降级 |
| Room | 保存广告和互动状态 |
| Remote | OkHttp 请求广告或服务端数据 |
| AI | 生成摘要、标签、对话搜索结果 |

## 当前代码要调整的点

| 现在 | 后续 |
| --- | --- |
| `MainActivity` 直接调 Repository | 改成调 `FeedViewModel` |
| `DetailActivity` 直接调 Repository | 改成调 `DetailViewModel` |
| Repository 内存保存状态 | Room 保存状态 |
| Mock 数据直接进列表 | Mock/网络数据先写 Room |
| 手动刷新列表同步状态 | 页面观察 Room 自动同步 |

## 页面流转

信息流：

```text
Feed 页面 -> FeedViewModel -> AdRepository -> Room -> RecyclerView
```

刷新：

```text
下拉刷新 -> Repository 拉 Mock/网络数据 -> 写 Room -> 页面自动更新
```

详情：

```text
列表点击 adId -> DetailViewModel 观察 Room -> 点赞/收藏写 Room -> 列表和详情同步
```

AI 对话式搜索：

```text
首页 AI 入口 -> AiChatActivity -> AiChatViewModel -> AiChatRepository
    -> AiChatRemoteDataSource -> AiChatResponseDto -> AiChatMessage -> RecyclerView
```

AI Chat 的 DTO 只停留在 `data/remote` 和 `data/repository`，ViewModel 和 UI 层只处理 `AiChatMessage`。
