# 技术约定

当前项目按 Android 原生方案推进。

## 已确定

- 语言：Kotlin
- UI：XML 布局，不使用 Compose
- 架构：逐步改成 MVVM
- 列表：RecyclerView
- 网络：OkHttp 后续接入
- 本地数据：Room，底层 SQLite
- 数据格式：JSON
- 图片：后续接 Glide 或 Coil
- 视频：AndroidX Media3 ExoPlayer

## 基本数据流

```text
Activity / Fragment
        ↓
ViewModel
        ↓
Repository
        ↓
Room / OkHttp / AI Service / Mock
```

## 当前状态

当前仓库已经进入阶段 6 网络和 AI 服务的 FakeRemote 形态建设：

- 首页广告列表
- 三个频道
- 搜索
- 下拉刷新
- 上滑加载
- 详情页
- 点赞、收藏、分享、曝光、点击
- 标签筛选
- Room 数据层
- FeedViewModel / DetailViewModel
- StateFlow 状态同步
- Media3 ExoPlayer 初步接入
- VideoPlaybackPool 共享播放器池
- 信息流视频完全入屏自动播放、完全离屏自动暂停
- 自定义视频控件：右上角静音常驻，中央播放/暂停和底部进度在用户点击后显示，1 秒无操作后淡出
- AI 对话式搜索页：通过聊天 UI 输入自然语言问题，当前使用 FakeRemote 模拟 C/S 响应 DTO

当前广告数据、互动状态、统计字段和视频播放/静音状态通过 Repository 读写 Room，列表页和详情页依靠 Room Flow + StateFlow 同步。视频能力已经接入 Media3 ExoPlayer，并从手动点击播放为主升级为信息流自动播放调度：MainActivity 判断 RecyclerView 中完全可见的视频卡片，FeedViewModel 接收可见性事件，VideoPlaybackPool 复用单个 ExoPlayer 绑定 PlayerView、暂停离屏视频并按广告 id 保留播放进度。播放、暂停和静音等轻量状态更新通过局部刷新处理，避免重绑播放器导致闪屏。

视频能力已完成主要实现，仍需继续验证播放、暂停、静音、1 秒自动隐藏控件、完全入屏自动播放、完全离屏自动暂停、详情页返回和释放流程。

网络接口、真实广告数据、真实 AI 摘要、智能标签和真实对话式搜索服务属于后续接入内容。当前 AI Chat 已先建立请求/响应 DTO 和 Repository 转换边界，后续主要替换 `AiChatRemoteDataSource`。

## 不做

- 不引入 Compose。
- 不直接在 Activity 里堆复杂逻辑。
- 不把内存 Map 当最终数据方案。
- 不在 FakeRemote 阶段接入真实网络和 AI 服务。
