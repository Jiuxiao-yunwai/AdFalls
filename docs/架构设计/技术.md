# 技术约定

当前项目按 Android 原生方案推进。

## 已确定

- 语言：Kotlin
- UI：XML 布局，不使用 Compose
- 架构：逐步改成 MVVM
- 列表：RecyclerView
- 网络：OkHttp
- 本地数据：Room，底层 SQLite
- 数据格式：JSON
- 图片：后续接 Glide 或 Coil
- 视频：后续接 VideoView 或 ExoPlayer

## 基本数据流

```text
Activity / Fragment
        ↓
ViewModel
        ↓
Repository
        ↓
Room / OkHttp / AI Service / Mock
```

## 当前状态

`main` 上已经有一个可运行的信息流 Demo：

- 首页广告列表
- 三个频道
- 搜索
- 下拉刷新
- 上滑加载
- 详情页
- 点赞、收藏、分享、曝光、点击
- 视频播放状态模拟

目前数据和状态主要存在内存 Repository 里。后面要改成 Room 统一存储，方便解释缓存、状态同步和跨页面数据一致性。

## 不做

- 不引入 Compose。
- 不直接在 Activity 里堆复杂逻辑。
- 不把内存 Map 当最终数据方案。
