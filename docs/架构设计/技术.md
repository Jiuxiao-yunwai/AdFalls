# 技术约定

当前项目按 Android 原生方案推进。

## 已确定

- 语言：Kotlin
- UI：XML 布局，不使用 Compose
- 架构：逐步改成 MVVM
- 列表：RecyclerView
- 网络：OkHttp 后续接入
- 本地数据：Room，底层 SQLite
- 数据格式：JSON
- 图片：后续接 Glide 或 Coil
- 视频：AndroidX Media3 ExoPlayer

## 基本数据流

```text
Activity / Fragment
        ↓
ViewModel
        ↓
Repository
        ↓
Room / OkHttp / AI Service / Mock
```

## 当前状态

当前仓库已经有一个阶段 5 进行中的信息流 Demo：

- 首页广告列表
- 三个频道
- 搜索
- 下拉刷新
- 上滑加载
- 详情页
- 点赞、收藏、分享、曝光、点击
- 标签筛选
- Room 数据层
- FeedViewModel / DetailViewModel
- StateFlow 状态同步
- Media3 ExoPlayer 初步接入
- VideoPlaybackPool 共享播放器池
- 信息流视频完全入屏自动播放、完全离屏自动暂停

当前广告数据、互动状态、统计字段和视频播放/静音状态通过 Repository 读写 Room，列表页和详情页依靠 Room Flow + StateFlow 同步。视频能力已经接入 Media3 ExoPlayer，并从手动点击播放为主升级为信息流自动播放调度：MainActivity 判断 RecyclerView 中完全可见的视频卡片，FeedViewModel 接收可见性事件，VideoPlaybackPool 复用单个 ExoPlayer 绑定 PlayerView、暂停离屏视频并按广告 id 保留播放进度。

视频能力仍处于播放、暂停、静音、完全入屏自动播放、完全离屏自动暂停、详情页返回和释放流程的收尾验证阶段。

网络接口、真实广告数据、真实 AI 摘要、智能标签和对话式搜索属于后续阶段 6，不在当前阶段实现。

## 不做

- 不引入 Compose。
- 不直接在 Activity 里堆复杂逻辑。
- 不把内存 Map 当最终数据方案。
- 不在阶段 5 收尾中接入真实网络和 AI 服务。
