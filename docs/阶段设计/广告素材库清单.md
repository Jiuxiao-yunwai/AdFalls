# 广告素材库清单

当前素材库采用本地 mock 方案，数据由 `AdRepository.fixedAds()` 写入 Room，再通过 `FakeAdRemoteDataSource` 模拟远程分页和搜索请求。

## 素材规模

- 总广告数：50 条
- 频道：精选 / 电商 / 本地
- 卡片类型：大图 / 小图 / 视频
- 视频来源：复用本地生成的 mp4 mock 资源
- 图片来源：暂用卡片颜色和现有 UI 样式模拟广告封面

## 主题覆盖

精选频道偏生活方式和场景推荐：

- 夜跑、露营、通勤咖啡、办公桌搭、护肤、骑行、家庭观影
- 晨间效率、旅行收纳、城市快闪、轻食、睡眠、数码、音乐节

电商频道偏商品售卖和消费决策：

- 服饰、清洁家居、学生数码、香氛礼盒、厨房小家电
- 户外鞋服、宠物设备、降噪耳机、筋膜仪、床品、咖啡器具、学习平板

本地频道偏附近服务和线下活动：

- 轻食店、艺术展、社区健身、亲子手作、街区咖啡、夜间市集
- 徒步路线、音乐现场、旧物交换、火锅套餐、书店夜读、骑行打卡

## 后续可替换项

- 将 `mediaColor` 替换为真实图片资源 id 或 assets 路径
- 将本地生成视频替换为真实短视频素材
- 将 `summary` 替换为云端大模型生成摘要
- 将 `tags` 替换为云端大模型智能标签
- 将 `FakeAdRemoteDataSource` 替换为真实服务器接口
